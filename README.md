# π² project page

Project website for **π²: A Simple Framework for 2D-to-3D Registration**.

Project URL: https://dengh293.github.io/p2i-project-page/

Research code: https://github.com/DengH293/P2I

## Website

The static page includes an interactive image–point-cloud registration demo using three KITTI examples, the paper figures, and a BibTeX citation. It runs entirely in the browser.

For local preview, run `python -m http.server 8768` from this directory and open http://localhost:8768/.

## GitHub Pages

Publish from the `main` branch and the `/(root)` folder in Settings → Pages. The `.nojekyll` file preserves the static assets as supplied.

Three.js and OrbitControls are distributed with their MIT license in `vendor/THREE-LICENSE.txt`. The KITTI examples are from the KITTI dataset; this repository does not change their original terms.
